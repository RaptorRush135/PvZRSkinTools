# 🌱 PvZRSkinTools

> Utility for extracting a converting Spine assets for *Plants vs. Zombies™: Replanted*.

## Features

- Spine convert:
    - Convert Spine skeleton and atlas files:
        -   3.8 <-> 4.2   (atlas and skeletons)
        - .skel <-> .json (skeletons)
- Extract bundle:
    - Extract assets from the bundle that contains the Spine content.
- GUID generator:
    - Create random GUIDs and copy them to the clipboard.

## Usage

Run `PvZRSkinTools/PvZRSkinTools.exe`.
